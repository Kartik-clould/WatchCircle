# WatchCircle

A social movie and TV series watchlist web application built using ASP.NET Web Forms, C#, ADO.NET and Microsoft SQL Server.

## Live Demo

🌐 **Live Website:** http://watchcircle.somee.com

The application is deployed on Somee using IIS and a remote MS SQL Server database.

## Features

- User registration and login
- Movie and TV series watchlist
- Watch status tracking
- Ratings and reviews
- Friend requests
- Friends list
- Friend profiles
- Dashboard statistics

## Technology Stack

- C#
- ASP.NET Web Forms
- .NET Framework 4.7.2
- ADO.NET
- Microsoft SQL Server
- HTML
- CSS
- Visual Studio
